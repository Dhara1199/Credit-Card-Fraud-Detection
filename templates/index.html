Pipeline

How the model was built

  1. Load the Kaggle credit card transaction dataset
  2. Split 80 / 20, stratified so fraud stays proportional
  3. Train Random Forest · 150 trees · balanced class weights
  4. Evaluate precision, recall, ROC-AUC and PR-AUC
  5. Serve via a Flask API to this console

Fraud is extremely rare, so a model that says "genuine" every time would still be 99.8% accurate. Recall and PR-AUC are the numbers that really matter.
